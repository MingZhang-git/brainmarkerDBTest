📂 上传您的数据 — 支持 CSV Marker列表 + Seurat 元数据（UMAP坐标 + 细胞注释）
① Marker 列表 (CSV/TSV)
📋
点击或拖入 Marker CSV
必需列：gene + celltype（或cluster）
Seurat输出可直接用，pct.1/pct.2自动识别
支持CSV/TSV，UTF-8或GBK编码
② UMAP 坐标 + 细胞注释 (CSV)
🗺️
点击或拖入 UMAP CSV
必需列：UMAP_1, UMAP_2 + celltype（或cluster）
支持umap1/umap_1等大小写变体
可选列：region, sample, seurat_clusters
📌 Seurat RDS 用户：请先在 R 中运行以下命令导出数据：
markers <- FindAllMarkers(seurat_obj, only.pos=TRUE)
write.csv(markers, "markers.csv")
meta <- cbind(seurat_obj@meta.data, Embeddings(seurat_obj, "umap"))
write.csv(meta, "umap_meta.csv")
📌 数据格式要求
Marker CSV 格式
列名说明必需
gene基因名称✅
celltype细胞类型标签✅
specificity特异性分数 0–1推荐
avg_expr平均表达量推荐
logFClog2 FoldChange推荐
pct1目标细胞表达比例推荐
pct2其他细胞表达比例推荐
p_adj校正p值推荐
region脑区标签推荐
UMAP CSV 格式
列名说明必需
UMAP_1UMAP 第一维坐标✅
UMAP_2UMAP 第二维坐标✅
celltype细胞类型标签✅
region脑区标签推荐
sample样本/批次ID可选
clusterSeurat Cluster ID可选
